# Model Efficiency Atlas

An interactive guide to how large language models differ and where their efficiency comes from: Mixture-of-Experts routing, KV cache memory, quantization, speculative decoding, thinking budgets and cost per task. Each idea is explained twice: once for a 5-year-old and once for an engineer.

Live page: https://venkatakrishnan-ramesh.github.io/awesome-llm-efficiency/

It's a single self-contained `index.html` with no build step. Open it in a browser to run it locally.
